# text-classification
Classifies text sentiment (positive/negative) using Hugging Face's DistilBERT (SST-2), with a Gradio-based web UI.

Create venv. Activate the venv. Install the requirements. Run the project. Then open the project in "http://127.0.0.1:7860".
